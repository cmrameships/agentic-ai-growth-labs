# Agentic AI Growth Labs

This repository demonstrates experiments with **agentic AI systems** capable of:

- generating technical content
- interacting with APIs
- running growth experiments
- optimizing subscription monetization

These experiments explore how autonomous AI systems can power the next generation of software products.

---

## Project 1: AI Technical Content Agent

An autonomous agent that generates developer articles and documentation.

Capabilities:

• topic research  
• article generation  
• publishing workflow  

Use cases:

- developer blogs
- documentation
- technical marketing

---

## Project 2: API Interaction Agent

An AI agent capable of interacting with APIs to gather data and make decisions.

Example integrations:

- OpenAI API
- analytics platforms
- subscription platforms

Goal:

Automate product experimentation and growth decisions.

---

## Project 3: Growth Experiment Agent

This system runs automated growth experiments such as:

• paywall experiments  
• onboarding tests  
• pricing optimization  

Inspired by the monetization infrastructure provided by RevenueCat.

## Vision

Agentic AI will transform apps into **self-optimizing systems**.

Instead of manually analyzing metrics and launching experiments, developers will design AI systems that continuously improve product growth.

This repository explores that future.
